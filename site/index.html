    How it works

    1. 1. Supersession lossless

      A file read that a later edit replaces, or an exact duplicate, carries nothing the final state does not. Those segments go first, before any lossy step. On the research corpus this alone removes about a quarter of all tokens.

    2. 2. Leverage in the session's own basis

      Each segment is embedded and the session's segment matrix is factored by SVD. That is the Karhunen–Loève transform JPEG approximates with the DCT, and it is affordable exactly because one session is small. A segment's leverage score is how strongly it loads on the retained principal directions.

    3. 3. Novelty per token

      The budget is filled greedily. Each candidate's leverage is discounted by the share of its words the kept set already has (to the power 0.5), then ranked per token, so a long segment does not win on size and repeats lose to fresh content.
